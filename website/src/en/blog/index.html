2. Core Architectural Pillars & Production Benchmarks

🔒 Local-First Security & 3-Tier CSRF Shield

Unlike cloud SaaS gateways that store session cookies on third-party servers, Zalo-Flow binds strictly to loopback 127.0.0.1:3000 on desktop environments. All Zalo credentials and LLM API keys are encrypted at rest using AES-256-CBC (SESSION_SECRET). State-mutating API endpoints are guarded by a 3-tier CSRF shield verifying Sec-Fetch-Site, custom X-ZaloFlow-Client: 1 headers, and strict origin matching.

⚡ Self-Healing Memory Watchdog & SQLite WAL

Engineered for high-volume accounts (> 2,000 friends and 260+ group chats), the runtime enforces a strict 350MB Node.js RAM ceiling (512MB in Docker). Before any graceful restart, the watchdog broadcasts an SSE notification, drains pending outbound queues via RateLimiter.drainAll(), and executes PRAGMA wal_checkpoint(TRUNCATE) to guarantee zero message loss.
