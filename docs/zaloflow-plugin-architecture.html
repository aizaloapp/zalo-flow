Zalo-Flow: Kiến Trúc Tương Lai Hệ Thống Plugin Cắm-Rút

Triết lý "Microkernel Bất Biến + Plugins Cắm Rút Linh Hoạt" — Bảo vệ 100% Anti-Ban Zalo cá nhân, siêu nhẹ RAM (<350MB) và mở rộng hệ sinh thái không giới hạn.

⚡ Lộ Trình Vận Hành & Luồng Xử Lý (Execution Timeline)
1

Lớp Phòng Thủ Anti-Ban (Ingress Shield)

Tin nhắn đến qua giao thức Zalo Web được đưa ngay qua Flood Detector (chặn >5 tin/3s) và Self-Echo Shield (bộ đệm 30s) chống vòng lặp phản xạ vô tận.

2

Điều Phối Qua Event Bus & Hook Lifecycle

Microkernel chuyển gói tin qua Event Bus trung tâm. Các plugin đã đăng ký hook onInbound() sẽ nhận sự kiện song song, không khóa luồng.

3

Lưu Trữ Bền Vững & Đối Soát SQLite

Bản ghi được nạp vào bảng messages và conversations với cơ chế WAL Checkpoint, mã hóa bí mật AES-256 và giữ vững Whitelist khi đổi tài khoản.

4

Kích Hoạt Các Plugin Chức Năng Cắm-Rút

Các plugin được kích hoạt theo nhu cầu người dùng: Bot AI phân tích ảnh/trả lời, Chatwoot đồng bộ hộp thư, hoặc Remarketing lọc theo thẻ màu.

5

Lãnh Địa Xuất Tin Nghiêm Ngặt (Safe Outbound)

Tuyệt đối không plugin nào được gọi thẳng zca-js. Mọi tin nhắn phản hồi PHẢI nạp vào Rate Limiter (giãn cách ≥3s, max 20 tin/phút) để bảo vệ nick Zalo.

6

Cổng Mở Rộng Ra Hệ Sinh Thái (MCP & Community)

Hệ thống mở cổng MCP Server và Webhook Event chuẩn quốc tế, cho phép kết nối với Agent AI bên ngoài (Cursor, Claude) và các phần mềm bán hàng KiotViet/Sapo.

Lãnh Địa Bất Biến (Hard Core)

  • • Trần RAM <350MB Node.js / Docker 512MB
  • • Token Bucket Rate Limiter (≥3s giãn cách)
  • • Cấm plugin gọi thẳng giao thức Zalo
  • • CSDL SQLite WAL & Session AES-256

Cắm Rút Linh Hoạt (Composable)

  • • 1-Click Bật/Tắt từng Plugin trên Web UI
  • • Tách rời hoàn toàn Zalo Cá nhân & OA
  • • Tắt module AI hoặc Chatwoot để hạ RAM <40MB
  • • Hot Module Reload (HMR) không sập Server

Hệ Sinh Thái Mở (Open Ecosystem)

  • • Chuẩn Model Context Protocol (MCP) quốc tế
  • • Webhook Inbound/Outbound n8n, Make, Flowise
  • • Bộ cài Desktop Windows (.exe) giữ nguyên 24MB
  • • Sẵn sàng cho Chợ Tiện Ích Cộng Đồng
