4 Tính Năng Cốt Lõi Đã Được Tối Ưu Tinh Tế

Đáp ứng trọn vẹn tiêu chí kỹ thuật và trải nghiệm người dùng

📦

1. Cài Đặt 1-Click (Inno Setup Chuẩn Quốc Tế)

Tự động giải nén và cấu hình vào thư mục %LOCALAPPDATA%\Programs\ZaloFlow. Đóng gói sẵn Node.js 22.14 LTS Portable. Có sẵn lối tắt Gỡ cài đặt (Uninstaller) sạch sẽ nếu không muốn dùng nữa.

⚡

2. Tự Mở Trình Duyệt & Chống Mở Trùng (Zero Race)

Chính máy chủ Node sau khi khởi động thành công sẽ tự kích hoạt mở trình duyệt Chrome/Edge. Nếu bạn bấm nhầm icon 2-3 lần, app tự nhận diện và mở lại tab web chứ không bao giờ sinh ra tiến trình chạy trùng.

🛡️

3. Tự Động Đổi Cổng Nếu Bị Kẹt (3000 ➔ 3001)

Nếu máy tính của bạn đã có phần mềm khác (hoặc Docker) chiếm cổng 3000, server tự động chuyển sang 3001 và mở đúng web. Không bao giờ để người dùng bị văng lỗi cổng.

🔒

4. Cô Lập Localhost (127.0.0.1) & Tắt App An Toàn

Khóa cứng kết nối vào máy tính cá nhân, an toàn tuyệt đối khi dùng Wi-Fi quán cà phê. Nút "Dừng Zalo-Flow" gọi lệnh tắt an toàn, xả hết tin nhắn và lưu trọn vẹn CSDL trước khi thoát.

3 Bước Triển Khai (Dự Kiến 1 - 1.5 Ngày)

Tiến độ cực nhanh và an toàn

Đã Phê Duyệt
1
Chuẩn hóa mã nguồn: Khóa 127.0.0.1, Đổi cổng kẹt & Tắt an toàn

Cấu hình cờ ZALOFLOW_PACKAGED=1, chặn Git pull backend, server tự mở browser, thêm endpoint shutdown an toàn.

2
Tạo kịch bản Inno Setup & Trình chạy ẩn không màn hình đen

Đóng gói Node 22.14 LTS Portable, viết launcher VBScript chạy ẩn tĩnh lặng, tạo shortcut Desktop và Start Menu.

3
Kiểm thử cài đặt thực tế & Thiết lập GitHub Actions tự đóng gói

Kiểm tra cài trên Windows, đo RAM ~60-80MB, tự động sinh file ZaloFlow-Setup.exe khi release trên GitHub.
