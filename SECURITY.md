# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and privacy of our users very seriously. If you discover a security vulnerability within `Zalo-Flow`, please follow these steps:

1. **DO NOT** disclose the vulnerability publicly in GitHub Issues, Discussions, or social media.
2. Please submit your findings through **GitHub Security Advisories** (Private Vulnerability Reporting).
3. Please include:
   - Type of vulnerability (e.g. Session disclosure, injection, rate limit bypass)
   - Step-by-step reproduction steps
   - Potential impact
4. The maintainers will review the report and provide an estimated fix timeline.
